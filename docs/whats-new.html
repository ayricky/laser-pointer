A new look, smoother strokes, a smoother settings panel, much less memory while idle, and fixes for the setups people actually present on. Everything below with two panels is live: draw on either side and both react.

A new look

1.0 had no icon of its own: Explorer and the taskbar showed the generic program icon, and the tray borrowed the Excalidraw pen. The new mark is the app's own stroke — a trail that tapers into a white-hot dot, drawn in the same layered Glow passes the app uses.

A real exe icon, Start-menu and Store tiles at every size, and a tray glyph that follows the taskbar's theme and lights up in your laser colour while it's on.

Fast flicks stay round

Windows merges mouse moves while an app is busy, so a quick flick could reach the app as a handful of far-apart points and come out as straight segments. 1.1 asks Windows for the in-between points it merged (GetMouseMovePointsEx) and draws through all of them. Flick quickly on either side; the left one only sees what 1.0 saw while busy.

A scripted loop at 1000 Hz, fed to both sides.
Before

Only the latest position each time the app gets round to it.

After

Every point the mouse reported, timed as it happened.

Annotations keep their look, and Clear can be undone

With Keep strokes on, 1.0 drew every annotation with the current pen, so switching from the highlighter to the pen repainted everything you'd already drawn. Now each stroke remembers its pen. Clear fades instead of popping, Undo right after Clear brings it all back, and there's Redo (Ctrl+Y).

Draw, switch pen, draw again — then Clear and Undo.
Before

Earlier strokes change with the pen; Clear pops; no way back; no Redo.

After

Strokes keep their pen; Clear fades over 250 ms; Undo restores; Redo works.

A smoother settings panel

The panel used to snap between states and repaint from a 16 ms timer that drifts against the screen's refresh, so its live preview stuttered — worst on 120 Hz and 144 Hz screens. It now presents in step with the display, sleeps when nothing moves, and uses Windows 11's motion timings. Try the controls on both sides.

Before

Instant state changes; preview paced by a timer.

After

Eased switches, sliding tab indicator, smooth scrolling, vsync-paced preview, and a gentle entrance when the panel opens. Off when Windows' animation effects are off.

Lighter on the machine

Measured on this PC with the benchmark in the repository (cargo test --release -- --ignored bench_overlay): an offscreen 2560×1440 surface with 150 kept annotations while one more is drawn, and the overlay's full-desktop buffers (this PC's desktop spans about 16.6 million pixels) before and after the idle trim.

CPU time per frame while annotating

150 kept annotations on screen while you draw one more. Finished annotations are drawn once into a cached layer instead of being rebuilt every frame. (CPU time to submit the frame; the GPU work shrinks the same way.)

Pixels sent to the screen per frame

Only the area around the stroke being drawn is presented, as several small rectangles instead of one large one.

GPU memory held while hidden

After 3 s hidden, the overlay shrinks its buffers and hands the memory back; it regrows them in a few milliseconds when you press the shortcut.

Projectors and mixed scaling

The most common presenting setup — a laptop at 150 % plugged into a projector at 100 % — tripped up 1.0 twice. Press the button to plug the projector in.

Then compare the stroke thickness on each screen.
Before

Plugging a screen in wiped every annotation. One scale for all screens made strokes 1.5× too thick on the projector (and the cursor the wrong size).

After

Annotations stay where they were. Stroke width, ripples, the indicator and the cursor follow each screen's own scaling.

Ready for the Microsoft Store

 

A first run you can see

A tray app launched from the Store used to vanish into the hidden-icons overflow. On first launch it now opens its settings and says which shortcut to press.

Start with Windows, the Store way

Packaged apps can't use the registry Run key, so the Store build uses a Windows startup task you can also manage in Settings › Apps › Startup.

MSIX package and assets

A one-command build script produces the Store package with every logo size Windows asks for, and CI builds it on every push.

Open source, with a home

MIT-licensed on GitHub, with this site, an interactive demo, a privacy policy (it collects nothing) and an about section in the app.
